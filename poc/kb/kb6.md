title: BranchDesk receipt printer offline
---
BranchDesk receipt printer offline: power cycle the printer and re-pair it in the BranchDesk settings page. If the printer still shows offline, check that the branch Wi-Fi allows the printer VLAN. Replace the printer if the test page does not print.
