title: WealthPlan report export returns 500 for large portfolios
---
WealthPlan report export returns 500 for large portfolios above 5000 holdings. The workaround is to export by date range in smaller slices. This is a known defect tracked in an open incident, so link to it instead of raising a duplicate.
